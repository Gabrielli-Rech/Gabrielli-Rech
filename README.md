## 🌟 Sobre mim

> "Programar é mais do que escrever código — é resolver problemas, criar experiências e dar vida a ideias. Sou movida pela curiosidade, aprendizado constante e pelo desejo de impactar o mundo através da tecnologia."

Sou uma desenvolvedora versátil com forte paixão pelo ecossistema **Web Full-Stack** e por **UI/UX Design**. Adoro estar envolvida em toda a jornada do produto: desde a prototipagem de uma interface amigável até a construção de uma arquitetura robusta no back-end.

Embora meu foco principal seja criar aplicações web incríveis, minha base técnica vai além: construo sistemas desktop, exploro integrações com IoT e estou sempre testando novas linguagens. Entre commits, deploys e a busca pela próxima platina na Steam, meu objetivo é simples: evoluir continuamente e entregar soluções de alto impacto.
